# Alfonso 1.1.15 (26)

- Neues Smartphone-Menü „App aktualisieren“ mit manueller GitHub-Release-Prüfung,
  installierter/verfügbarer Version und Änderungsbeschreibung.
- APK-Download mit Fortschritt, Abbruch und Wiederaufnahme des Downloadstatus.
- Prüfung von Dateigröße, SHA-256, Application-ID, versionCode, versionName und
  kryptografischer APK-Signatur vor Übergabe einer privaten Kopie an Android.
- Geführte Freigabe „Apps aus dieser Quelle installieren“; Installation kann nach
  Rückkehr oder Abbruch fortgesetzt werden. Keine stille Installation.
- App-Name Alfonso, Paketkennung und ursprünglicher Signierschlüssel bleiben
  erhalten. Einstellungen und Verlauf werden nicht zurückgesetzt.

Die erste Installation dieser Version erfolgt durch Öffnen der beigefügten APK.
Künftige Updates können über das App-Menü geladen werden. Geräteprüfung von
Google/Gemini-Sprachaufruf, Installationsdialog, Widget und Android Auto steht aus.
